Where vendor skill texts also appear

Every SKILL.md file in public GitHub repositories (from GitSkills) that is byte-identical to a version a vendor published. Edited copies are not counted yet. A vendor's own skills come first: each text is credited to the earliest path where a vendor published it as its own. Skills a vendor only repackaged, whose plugin manifest or partner folder names another author, are striped and counted apart, so a vendor isn't credited with someone else's work. A skill that a vendor later moved or republished can show no copies under its newer path.
