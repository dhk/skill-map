Where vendor skill texts also appear

Every SKILL.md file in public GitHub repositories (from GitSkills) that is byte-identical to a version a vendor published. Edited copies are not counted yet. Each text is credited only to the earliest vendor path that published it, so a skill that a vendor later moved or republished can show no copies under its newer path.

From vendor, to skill, to where copies land

The middle column shows the skills found in the most repositories, the same ranking as the graph and the table; the rest of each vendor's skills are grouped. Band width is the number of files, because files add up across columns and repositories don't (one repository can hold a skill in several folders). The right column is the agent folder the file sits in.
